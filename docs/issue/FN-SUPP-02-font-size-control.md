## 요청 유형

- [x] 새로운 기능 추가

## 어떤 기능인가요?

헤더의 글자 크기 버튼(100%/125%/150%)으로 웹 전체 텍스트 크기를 동적 조절한다.

## 이 기능이 필요한 이유는 무엇인가요?

시니어 사용자의 시력 고충을 반영해 가독성을 높인다.

## 구현 방안

**Frontend 전용, 백엔드/DB 작업 없음**
- Root HTML `font-size` CSS 변수 또는 REM 단위 가변 적용
- 선택값 LocalStorage에 저장, 페이지 이동 시에도 유지
- 확대 시 레이아웃 깨짐 없는지 반응형 검증

## 작업 상세 내용

- [ ] 헤더 글자 크기 컨트롤러 UI (100%/125%/150%)
- [ ] REM/CSS 변수 기반 전역 폰트 스케일링
- [ ] LocalStorage persist
- [ ] 150% 확대 시 주요 화면 레이아웃 QA

## 완료 기준

버튼 클릭 즉시 화면 전체 텍스트 크기가 지정 비율로 변경되고, 레이아웃이 깨지지 않는다.
