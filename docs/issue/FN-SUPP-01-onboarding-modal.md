- [x] 새로운 기능 추가

## 어떤 기능인가요?

유언대용신탁 개념을 쉬운 비유("살아계실 땐 월세 받으시고 사후엔 자녀에게 안전하게 전달하는 통장 잠금장치")로 설명하는 온보딩/가이드 모달.

## 이 기능이 필요한 이유는 무엇인가요?

개념이 생소한 사용자의 서비스 이해도를 최초 진입 시점에 높인다.

## 구현 방안

**Frontend 전용, 백엔드/DB 작업 없음**
- 최초 진입 시 온보딩 모달 노출, 상단 메뉴 `[서비스 안내]`로 재호출 가능
- `[오늘 하루 보지 않기]` 클릭 시 LocalStorage에 상태 저장, 24시간 재노출 방지

## 작업 상세 내용

모달 닫기 클릭 시 정상적으로 랜딩/시뮬레이터 화면으로 전환된다.
